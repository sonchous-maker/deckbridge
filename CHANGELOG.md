# Changelog

## 0.1.0 — Preview

- Export selected Figma frames or slides to PPTX with editable text and supported shapes.
- Import supported PPTX content into editable Figma frames.
- Provide an English interface, progress messages, and conversion warnings.
- Convert imported text sizes from points to pixels for base text and styled runs.
- Wait for clipped PNG export before removing temporary nodes.
- Preserve empty intersections through nested clipping regions.
- Treat layers named `ignore` as ordinary layers; only `img` and `svg` naming rules remain.

This is a preview release. Theme/layout inheritance and several PowerPoint features are not fully supported. Figma Slides compatibility and visual fidelity still require manual validation.
